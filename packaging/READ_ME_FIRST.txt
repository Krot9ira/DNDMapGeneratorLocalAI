D&D AI BATTLE MAP GENERATOR
===========================

Начните отсюда. Всё, что нужно, уже лежит в этой папке.


ЧТО ЭТО
-------
Вы описываете место одним предложением - «порт с большим кораблём», «затопленный
склеп», «таверна». Программа сама придумывает планировку, чертит схему и рисует
по ней готовую боевую карту вида сверху. Её можно сразу загрузить в Roll20 или
Foundry.


ЧТО НУЖНО ЗАПУСТИТЬ ДО СТАРТА
-----------------------------
Программа сама ничего не рисует - она распоряжается двумя сервисами на вашем
компьютере. Оба должны быть уже запущены:

  1. ComfyUI            - рисует картинку.  http://127.0.0.1:8188
  2. Ollama (не обязателен) - придумывает план по описанию.
                              http://127.0.0.1:11434

Без Ollama всё работает: кнопка «Blueprint only» строит планировку мгновенно и
без языковой модели.

В ComfyUI должны лежать файлы моделей:

  models/diffusion_models/ideogram4_fp8_scaled.safetensors
  models/diffusion_models/ideogram4_unconditional_fp8_scaled.safetensors
  models/text_encoders/qwen3vl_8b_fp8_scaled.safetensors
  models/vae/flux2-vae.safetensors

Оба файла ideogram4 обязательны: без второго картинка выйдет размытой.


КАК НАЧАТЬ
----------
  1. Запустите DndBattlemapGenerator.exe
  2. Вкладка Settings -> кнопка «Test both connections».
     Строка ComfyUI должна стать зелёной.
  3. Вкладка Create -> опишите сцену, выберите стиль и размер.
  4. Нажмите MAKE MY BATTLE MAP и подождите несколько минут.

Готовая карта появится в окне и в папке output.


ЧТО В ЭТОЙ ПАПКЕ
----------------
  DndBattlemapGenerator.exe   сама программа
  config.json                 адреса сервисов и имена моделей
  styles/                     библиотека стилей, редактируется в программе
  presets/                    сохранённые карты
  output/                     сюда складываются результаты
  tools/                      командная строка и API для ИИ-агентов
  docs/Руководство.pdf        подробное руководство на 12 страниц
  AGENTS.md                   инструкция для ИИ-агентов


ПОДРОБНОЕ РУКОВОДСТВО
---------------------
docs/Руководство.pdf - написано для человека, который никогда не открывал
ComfyUI. Там разобрана каждая вкладка, каждая кнопка и что делать, если
что-то пошло не так.


КОМАНДНАЯ СТРОКА
----------------
Нужен Python 3.10+ и пакет Pillow (pip install pillow):

  python tools/pipeline.py styles
  python tools/pipeline.py auto "порт с большим кораблём" --style city_harbour

Для ИИ-агентов смотрите AGENTS.md.
